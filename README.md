# StingerReadded
This mod adds Stinger, an unused skill, back into the game.  It also adds a new skill that acts as a prerequisite for Stinger.  
This mod needs to be on both the Client and the Server to work properly.  
This mod requires that you also have https://github.com/CG-Nik/CustomSkillsAPI downloaded to work properly.  
https://github.com/CG-Nik/HandOnSideStructurePatch is highly suggested to be downloaded as well.  

Specifically, this mod adds a "Progression Slot" for Stinger to the Warrior Shrine's skill tree.  
Progression Slots are the physical bubble that represents a skill and allows you to obtain it through normal gameplay.  
Effectively, this mod makes Stinger obtainable in normal gameplay, as if it were a normal melee skill.  
It also adds a new skill, Side Power Hit, that functions as the prerequisite for Stinger.  Side Power Hit is an alternate version of Power Hit that does more damage, but requires that you charge it up like Stinger.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
